## Supervised Regression Model Workflow

This folder provides the supervised-learning workflow used for property regression. The workflow converts polymer/formulation SMILES into pooled Morgan-fingerprint features, trains baseline and optimized regression models, evaluates model performance by hold-out or cross-validation.

## 1. Folder structure

## 2. Data flow and file format

The supervised regression workflow contains three major data stages:

1. The original SMILES/formulation CSV is converted into Morgan fingerprint features.
2. The generated Morgan-feature CSV is used as the input for regression model training.
3. The selected best model is used to predict properties for new candidates and export a CSV-format property database.

---

### 2.1 Input file for Morgan fingerprint generation

The input file for `morgan_pooling.py` should be a CSV table containing SMILES columns, an optional ID column, and the target property column.

For Young's modulus regression, the target column is:

```text
Young's Modulus (kPa) log10
```

A minimal input table is:

| row_index | SMILE A | SMILE B | SMILE C | Young's Modulus (kPa) log10 |
|---:|---|---|---|---:|
| 0 | `[*]CC=CCCC(C#N)[*]` |  |  | 0.752 |
| 1 | `[H]N(C([H])([H])C(N([H])C(C)([H])C(N(C([H])([H])C([*])=O)[H])=O)=O)C(C(N([*])[H])(C)[H])=O` | `[*]OC1C(C(O)=O)OC(OC2C(NC(C)=O)C([*])OC(CO)C2O)C(O)C1O` |  | 0.911 |
| ... | ... | ... | ... | ... |

The script converts the SMILES strings into a 1024-dimensional pooled Morgan fingerprint vector. The target property and ID-related columns are preserved when specified.

The output feature CSV has the following structure:

| row_index | Young's Modulus (kPa) log10 | fp_0 | fp_1 | ... | fp_1023 |
|---:|---:|---:|---:|---|---:|
| 0 | 0.752 | 0 | 1 | ... | 0 |
| 1 | 0.911 | 2 | 0 | ... | 1 |
| ... | ... | ... | ... | ... | ... |

Here, `fp_0` to `fp_1023` are the Morgan fingerprint features.

---

### 2.2 Input file for regression model training

The Morgan-feature CSV generated above is used as the input file for model training.

The model-training script automatically uses numerical feature columns as input variables and uses the specified target column as the regression label.

The main outputs include:

| Output file | Description |
|---|---|
| `metrics.json` | Hold-out training and validation metrics. |
| `cv10_metrics.csv` | R², RMSE and MAE for each cross-validation fold. |
| `cv10_summary.json` | Mean and standard deviation of cross-validation metrics. |
| `fold_models/fold_XX_best_model.joblib` | Model file saved for each fold. |
| `best_model.joblib` | Model file used for downstream prediction. |
| `fold_XX_train.csv` | Training predictions for a specific fold. |
| `fold_XX_valid.csv` | Validation predictions for a specific fold. |

The key model-performance metrics are:

```text
R2
RMSE
MAE
```

---

### 2.3 Prediction output and CSV-format property database

After model comparison, the best-performing model should be selected according to validation or cross-validation metrics. The selected model file should be named:

```text
best_model.joblib
```

and placed under the directory specified by `--model_dir`.

For example, if fold 8 gives the best validation performance, the model can be copied or renamed as:

```text
fold_models/fold_08_best_model.joblib  ->  fold_models/best_model.joblib
```

The final output is a CSV-format property database. A minimal output format is:

| Pair_ID | SMILE A | SMILE B | row_index | RF_YoungsModulus_pred |
|---|---|---|---:|---:|
| Pair_1 | `[*]NC(C(N1CCCC1C(NCC(N2CC(CC2C(NC(C(NCC([*])=O)=O)CO)=O)O)=O)=O)=O)CCCCN` | `[*]NC(CCCCNC(C(C)=C)=O)C(N1CCCC1C(NCC(N2CC(O)CC2C(NC(COC(C(C)=C)=O)C(NCC([*])=O)=O)=O)=O)=O)=O` | 0 | 2.723 |
| Pair_2 | `OCC(C(C(C1N)O)O[*])OC1OC2C(OC(C(C2O)N)[*])CO` | `[*]NC(C(N1CCCC1C(NCC(N2CC(CC2C(NC(C(NCC([*])=O)=O)CO)=O)O)=O)=O)=O)CCCCN` | 1 | 5.555 |
| ... | ... | ... | ... | ... |

Here, `RF_YoungsModulus_pred` is the predicted property value generated by the trained regression model.

If additional columns are present in the original source CSV, they can also be preserved in the final prediction output.

## 3. Top-level pipeline scripts

The three Python scripts in the root directory of `Regression_Model/` are high-level controller scripts. They are used to connect the feature-generation, model-training, prediction, model-selection and plotting modules.

| Script | Role | Main function |
|---|---|---|
| `run_pipeline.py` | Top-level one-click pipeline | Runs `regression_main.py`, checks `model_candidates_for_llm.json`, calls `API/advise_best_model_with_api.py`, and then runs `draw_pipline.py`. |
| `regression_main.py` | Main regression controller | Generates Morgan features, runs RF/MLP/SVM/OLS training, runs RF/MLP/SVM grid search, selects the best fold model according to R², copies it as `best_model.joblib`, and optionally predicts new candidates. |
| `draw_pipline.py` | Automatic plotting controller | Reads the CV metric files, finds the fold with the highest R² for each model, locates the corresponding train/validation prediction CSV files, and calls `draw/draw_r2.py` to generate scatter plots. |

Their relationship is:

```text
run_pipeline.py
│
├── regression_main.py
│   ├── main_regression/morgan_pooling.py
│   ├── main_regression/baseline_RF.py
│   ├── main_regression/train_mlp_svm_pipeline.py
│   ├── main_regression/baseline_OLS_linear_regression.py
│   ├── grid/rf_grid_loop.py
│   ├── grid/grid_mlp.py
│   ├── grid/grid_svm.py
│   └── predict/predict.py
│
├── API/advise_best_model_with_api.py
│
└── draw_pipline.py
    └── draw/draw_r2.py
```


## 4. Running examples

All commands below assume that the current working directory contains the corresponding Python scripts. Paths such as `Path/...` should be replaced by user-defined local paths.

### 4.1 Generate Morgan fingerprints
```bash
python main_regression/morgan_pooling.py \
  --in_csv ../DataBase/youngs_modulus.csv \
  --polymer_cols "SMILE A" "SMILE B" "SMILE C" \
  --target_col "Young's Modulus (kPa) log10" \
  --alpha 3 \
  --radius 3 \
  --nbits 1024 \
  --out_csv results/YoungsModulus/features/youngs_modulus-pooled-morgan.csv
```

### 4.2 Train RF regression model
```bash
python main_regression/baseline_RF.py \
  --in_csv results/YoungsModulus/features/youngs_modulus-pooled-morgan.csv \
  --target "Young's Modulus (kPa) log10" \
  --model rf \
  --seed 42 \
  --save_dir results/YoungsModulus/rf_cv10 \
  --cv10 \
  --cv_folds 10 \
  --save_train_pred \
  --rf_n_estimators 400 --rf_max_depth 15 --rf_max_features 0.2 \
  --rf_min_samples_leaf 2 --rf_min_samples_split 12
```

### 4.3 Train MLP and SVM models
```bash
python main_regression/train_mlp_svm_pipeline.py \
  --in_csv  results/YoungsModulus/features/youngs_modulus-pooled-morgan.csv \
  --target  "Young's Modulus (kPa) log10" \
  --out_root results/YoungsModulus/runs
  --cv10 1 \
  --cv_folds 10
```
  
### 4.4 Train OLS linear regression baseline
```bash
python baseline_OLS_linear_regression.py
```

### 4.5 Predict new candidates
Before prediction, make sure that `--model_dir` contains a file named `best_model.joblib`.
If a fold-specific model is used, copy or rename the selected fold model, for example:

fold_models/fold_08_best_model.joblib  ->  fold_models/best_model.joblib
```bash
python predict/predict.py \
  --in_csv "../High-throughput predict/kmeans-pooled.csv" \
  --source_csv "../High-throughput predict/kmeans_results.csv" \
  --out_csv results/YoungsModulus/predictions/RF_best_pred_kmeans_results.csv \
  --model_dir Path/rf_cv10/fold_models/ 
```

### 4.6 Run RF grid search
```bash
python grid/rf_grid_loop.py \
```

### 4.13 One-click full pipeline

The recommended one-click entry point is:

```bash
python run_pipeline.py
```

This script automatically runs the following steps:

1. Run `regression_main.py` for Morgan feature generation, model training, grid search and prediction.
2. Check whether `results/YoungsModulus/model_candidates_for_llm.json` exists and is valid.
3. Run `API/advise_best_model_with_api.py` to generate `overall_best_model.json`.
4. Run `draw_pipline.py` to generate R² scatter plots for the best fold of each model.

The default input and output paths are defined inside `run_pipeline.py`. To use different files, either modify the paths in `run_pipeline.py` or run `regression_main.py` manually with command-line arguments.
