### All unsupervised learning scripts are run in the unsupervised environment.

### In the unsupervised_learning folder:

- 1.data-process.py
Purpose:
Merge the Young’s modulus and swelling ratio databases into a unified dataset for unsupervised learning.

Input:
- ../database/youngs_modulus.csv
- ../database/swelling_ratio.csv

Processing:
- Standardize the column schema of the two databases
- Merge them into one table
- Retain only rows containing exactly two non-empty SMILES entries
- Convert "Young's Modulus (kPa) log10" to "Young's Modulus (kPa)"

Output:
- final_two_smiles_with_modulus.csv

Run:
```bash
python data-process.py
```

- 2.morgan.py
Purpose:
Generate 1024-dimensional Morgan fingerprint representations for the two-component molecular systems.

Input:
- final_two_smiles_with_modulus.csv

Processing:
- Standardize SMILE A and SMILE B
- Generate 1024-bit Morgan count fingerprints for each component
- Apply average pooling to combine the two component fingerprints

Output:
- AB_concat1024.npy

Run:
```bash
python morgan.py
```

- 3.unsupervised.py
Purpose:
Perform PCA + UMAP + KMeans clustering on the 1024-dimensional Morgan fingerprints, and save both the clustering visualization and the cluster-specific CSV files.

Input:
- AB_concat1024.npy
- final_two_smiles_with_modulus.csv

Processing:
- Reduce fingerprint vectors from 1024D to 64D using PCA
- Project the data into 2D using UMAP
- Cluster the 2D embedding using KMeans (K=6)
- Save one CSV file for each cluster
- Plot the 2D UMAP clustering result with colored points and ellipses

Output:
- clusters/cluster_0.csv to clusters/cluster_5.csv
- cluster_umap_kmeans.png

Run:
```bash
python unsupervised.py
```

- 4.analyze_unsupervised.py
Purpose:
Analyze the cluster-specific CSV files generated by unsupervised clustering and compute property-based statistics for each cluster.

Input:
- clusters/cluster_*.csv

Processing:
- Count total samples in each cluster
- Count samples with swelling ratio >= 9
- Count samples with Young’s modulus between 100 and 2000 kPa
- Compute the corresponding fractions within each cluster

Output:
- clusters/cluster_statistics.csv

Run:
```bash
python analyze_unsupervised.py
```

- 5.unsupervised_learning_automation.py
Purpose:
Automatically execute the full unsupervised learning workflow, including data preprocessing, fingerprint generation, clustering, cluster analysis, best-cluster selection, and export of candidate combinations for subsequent supervised prediction.

Pipeline:
1. Run data-process.py
2. Run morgan.py
3. Run unsupervised.py
4. Run analyze_unsupervised.py
5. Run umap2d-kmeans.py
6. Run Best_classification_response.py to determine the best cluster
7. Run smiles_count_AB.py on the selected cluster
8. Copy the final selected result to:
   ../../Supervised_Learning/High-throughput predict/kmeans_results.csv

Validated outputs:
- final_two_smiles_with_modulus.csv
- AB_concat1024.npy
- cluster_umap_kmeans.png
- clusters/cluster_statistics.csv
- cluster_umap_kmeans_from_npy.png

Final output:
- ../../Supervised_Learning/High-throughput predict/kmeans_results.csv

Run:
```bash
python unsupervised_learning_automation.py
```

- Additionally, running the command below directly reproduces the unsupervised classification results in the paper:
umap2d-kmeans.py
Purpose:
Perform KMeans clustering directly on a precomputed 2D UMAP embedding and generate the corresponding visualization and cluster-specific CSV files.

Input:
- umap2d.npy
- final_two_smiles_with_modulus.csv

Processing:
- Load the saved UMAP 2D coordinates
- Perform KMeans clustering (K=6)
- Save one CSV file for each cluster
- Plot the 2D UMAP clustering result with colored points and ellipses

Output:
- clusters-from-umap/cluster_0.csv to clusters-from-umap/cluster_5.csv
- cluster_umap_kmeans_from_npy.png

Run:
```bash
python umap2d-kmeans.py
```

### In the candidate_umap folder:

- 1.all_AB_smiles2morgan.py
Purpose:
Extract all SMILES appearing in the original databases, generate all unique A/B pairwise combinations, and compute 1024-dimensional Morgan fingerprints for all candidate combinations.

Input:
- ../database/swelling_ratio.csv
- ../database/youngs_modulus.csv

Processing:
1. Extract all SMILES from SMILE A / SMILE B / SMILE C
2. Count the occurrence frequency of each unique SMILES
3. Generate all unique pairwise A/B combinations
4. Compute 1024-dimensional Morgan fingerprints for each A/B combination

Output:
- smiles_count.csv
- smiles_count_random_2.csv
- all_random_smiles_AB_concat1024.npy

Run:
```bash
python all_AB_smiles2morgan.py
```

- 2.cluster-3-AB-morgan.py
Purpose:
Process the supervised-prediction result files for selected SMILES pairs, convert Young’s modulus from log scale to linear scale, and generate 1024-dimensional Morgan fingerprints for downstream UMAP analysis.

Input:
- Prediction-1028-ALL2.csv
- Prediction-1028-ALL2-candidate.csv

Processing:
1. Convert "Young's Modulus (kPa) log10" to "Young's Modulus (kPa)"
2. Save processed CSV files
3. Generate 1024-dimensional Morgan fingerprints for each A/B pair

Output:
- Prediction-1028-ALL2-process.csv
- Prediction-1028-ALL2-1024.npy
- Prediction-1028-ALL2-candidate-process.csv
- Prediction-1028-ALL2-candidate-1024.npy

Run:
```bash
python cluster-3-AB-morgan.py
```

- 3.umap-candidate.py
Purpose:
Generate the UMAP distribution plot for the candidate components by jointly embedding the full A/B combination space, the supervised-prediction subset, and the final candidate set.

Input:
- all_random_smiles_AB_concat1024.npy
- Prediction-1028-ALL2-1024.npy
- Prediction-1028-ALL2-candidate-1024.npy
- Prediction-1028-ALL2-process.csv

Processing:
1. Concatenate the three fingerprint datasets
2. Perform PCA reduction to 64 dimensions
3. Perform UMAP projection to 2 dimensions
4. Plot the full background, prediction subset, and candidate components in one figure
5. Export the UMAP coordinates of the final candidate components

Output:
- umap_candidate_visualization.png
- candidate_umap_coordinates.csv

Run:
```bash
python umap-candidate.py
```

- 4.candidate_umap_automation.py
Purpose:
Automatically execute the full candidate UMAP workflow, including generation of the full A/B combination fingerprint space, processing of the predicted/candidate pairs, and UMAP visualization of the final candidate components.

Pipeline:
1. Run all_AB_smiles2morgan.py
2. Run cluster-3-AB-morgan.py
3. Run umap-candidate.py

Validation:
- all_random_smiles_AB_concat1024.npy
- Prediction-1028-ALL2-candidate-1024.npy
- umap_candidate_visualization.png

Key output:
- umap_candidate_visualization.png

Run:
```bash
python candidate_umap_automation.py
```
