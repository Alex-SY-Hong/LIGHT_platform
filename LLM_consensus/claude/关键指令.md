# 关键指令

## 项目相关指令

### Python 环境
- 使用 `.venv/Scripts/activate.bat` 作为项目的 Python 虚拟环境
- 所有 Python 指令都需要在该环境中运行
- 运行 Python 指令前需先执行：`.venv/Scripts/activate`

### 一键运行流程（推荐）
```bash
# 激活虚拟环境并运行完整流程
.venv\Scripts\activate
python run_pipeline.py
```

这将自动执行：
1. 数据提取
2. 数据修复（自动修复 GPT-5 Run 5 的 Winner 数据）
3. 可靠性分析（包括新的 Winner Margin 分析）
4. 生成可视化图表
5. 生成中英文 LaTeX 报告

### 忽略规则
- 忽略 stash~ 目录下的所有内容
- 不修改原始 `.md` 文件（用户要求）

## 可视化包使用

- 所有可视化功能已模块化到 `visualization/` 目录
- 使用方式：
  ```python

  from visualization import *

  # 或导入特定函数
  from visualization import plot_overall_comparison, plot_cv_comparison

  # 加载数据
  data = load_analysis_data()

  # 生成图表
  plot_overall_comparison(data, base_dir=".", save=True, show=False)
  ```

### 1. GPT-5 Run 5 数据提取问题
- **问题**: GPT-5 Run 5 的 "Selected Formula" 缺少配方编号
- **影响**: 导致 Winner=NaN，有效run数减少到10
- **解决**: 自动修复（run_pipeline.py 第43-101行）

## 新增功能

### Winner Margin 分析
- **目的**: 评估 cascading divergence 风险
- **指标**:
  - 平均得分差（最优-次优）
  - 风险等级：高(<1.0) / 中(<2.0) / 低(<3.0) / 极低(≥3.0)
- **结论**: Claude Opus 4.5 存在中风险，部分run中决策不够稳定
