# 提示词敏感性分析报告（Prompt Sensitivity Analysis）

探索性任务：`temp/prompt_sensitivity/`（半封闭系统，不影响外部数据）。
日期：2026-09-11。全部数据由本实验实际调用 API 产生，无任何虚构。

## 1. 问题与动机

项目所有头条结论（各模型 winners）都来自单一评分提示词 `prompt.md`。
本实验回答：**结论对该提示词的措辞、顺序、乃至评分范式本身是否稳健？**

## 2. 实验设计

### 2.1 提示词变体（由 `make_variants.py` 从原提示词程序化生成）

| 变体 | 扰动类型 | 内容 |
|------|----------|------|
| V1 `v1_reorder` | 良性 | 候选公式呈现顺序反转（10→1） |
| V2 `v2_paraphrase` | 良性 | 锚点描述、参数说明、winner 规则改写（语义不变） |
| V3 `v3_no_optimization` | 结构性 | 删除"约束优化"评分范式，改为按文献常规形态评估 |

### 2.2 模型与运行数（诚实说明）

- 原设计：4 模型 × (基线 + 3 变体) × 5 次，温度 0.0。
- **中途变故**：网关下线 `grok-4` 与 `claude-opus-4-5-20251101`（404 Model not found，
  30 次调用全部返回空响应）。改用后继模型 `grok-4-5`（正式迭代版本，思考能力层级
  贴近原 grok-4）与 `claude-opus-4-6`，并为其**在本实验内重新采集基线**
  （基线 n=5，同一提示词原文）。
- 应"最小可行分析"要求，替代模型的变体运行数为 n=3（modal winner 需 n≥3；
  ρ/位移类指标基于均值表，对 n 不敏感）。
- gemini-3-pro-preview 与 gpt-5 沿用根目录基线（11 次）。

### 2.3 指标与噪声基准

- Winner 稳定性：各条件 modal winner 是否等于基线 modal winner。
- 排序稳健性：平均 Total_Score 的 Spearman ρ（变体 vs 基线）。
- 维度级位移：各维度平均分 |Δ| 相对"噪声地板"（基线跨次 std 的均值），
  >2× 记为显著位移。
- Top-3 Jaccard。
- **无扰动参照**：基线折半（前后两半互比）给出同指标的噪声水平，
  变体效应须与该噪声比较而非与零比较。

## 3. 结果

### 3.1 Winner 稳定性（图 a）

**12 个 变体×模型 组合中 10 个 winner 不变。**

| 模型 | 基线 modal winner | V1 | V2 | V3 | 折半参照 |
|------|------------------|----|----|----|----------|
| Gemini-3 Pro | F4 (11/11) | F4 = | F4 = | F4 = | F4 = F4 |
| GPT-5 | F5 (10/11) | F5 = | F5 = | F5 = | F5 = F5 |
| Grok-4.5 | F5 (3/5) | F5 = | F5 = | **F4 ✗** | **F5 vs F4** |
| Claude Opus 4.6 | F4 (2/5) | F4 = | F4 = | F4 = | **F4 vs F5** |

唯一变体翻转：V3/grok-4-5（F5→F4）。关键背景：发生翻转的这个基线本身就不稳——
grok-4-5 基线 modal winner 仅 3/5（F5 3 次、F4 2 次），且其**无扰动折半参照自身
就翻转**（前半 F5、后半 F4，ρ=0.781）；claude-opus-4-6 同样折半自翻转
（F4 vs F5，ρ=0.452）。相反，基线 winner 稳定的两个模型（Gemini 11/11、
GPT-5 10/11）在全部三个变体下 winner 均不变。另可观察：grok-4-5 在 V3 下的
F4 与原版 grok-4 基线偏好一致，但我们不对此作任何主张。

### 3.2 排序稳健性（图 b）

全部 ρ ∈ [0.64, 0.98]，无任何条件接近 0.5 随机线：

| 模型 | 折半 ρ（噪声参照） | V1 | V2 | V3 |
|------|-------------------|----|----|----|
| Gemini-3 Pro | 1.000 | 0.806 | 0.794 | 0.976 |
| GPT-5 | 0.976 | 0.952 | 0.973 | 0.976 |
| Grok-4.5 | 0.781 | 0.815 | 0.815 | 0.752 |
| Claude Opus 4.6 | 0.452 | 0.808 | 0.636 | 0.681 |

三种视角都必须报告：
- Gemini 的噪声参照为 1.000，其 V1/V2 的 ρ≈0.79–0.81 **低于噪声参照**，
  说明候选顺序与措辞确实扰动其排序细节（但 winner 不变）。
- Grok-4.5 的变体 ρ（0.75–0.82）围绕自身噪声参照（0.781）波动，
  即变体效应与其固有抽样噪声不可区分。
- Claude 相反：噪声参照仅 0.452，其变体 ρ（0.64–0.81）**全部高于自身噪声**，
  即提示词扰动的影响小于模型自身抽样噪声。

### 3.3 结构性扰动（V3）

V3 的效果必须如实分层报告：
- 对基线 winner 稳定的模型（Gemini、GPT-5），V3 **未改变 winner**，且其 ρ
  （0.976）处于各自噪声参照水平——范式框架不是这两个模型结论的脆弱来源。
- 对基线不稳定的模型（Grok-4.5），V3 下 winner 翻转（F5→F4）；但该模型的
  winner 本身在其无扰动折半中就翻转，故此翻转在噪声范围内，不能归因于范式
  删除本身。
- Claude 的 winner 在 V3 下保持（F4），尽管其基线弱多数。
- 总体上 V3 的 ρ（0.68–0.98）与良性变体相当，未出现系统性坍塌。

**结论：没有证据表明"约束优化"范式框架是结论的主要脆弱来源；
winner 层面的不确定性主要集中在基线自身不稳定的模型上。**

### 3.4 维度级分数较脆弱（图 c）

Winner 与排序稳健，但维度分数存在局部显著位移：
- Thrombogenicity：V1 平均位移达噪声 3.2×，V2 2.6×（>2× 线）。
- Mechanical_Safety：V3 达 2.3×。
- Gemini 在 V1 下有 3 个维度位移 >2× 噪声；grok-4-5 在 V3 下有 2 个。

**结论层级：winner > 排序 > 维度分。维度级分数对提示词最敏感，
不宜作为独立结论引用。**

## 4. 诚实的限制

1. **替代模型**：grok-4-5 / claude-opus-4-6 ≠ 原 grok-4 / claude-opus-4-5。
   旁证：grok-4-5 基线偏好 F5（且在 F4/F5 间摇摆），而原 grok-4 基线偏好
   F4——模型差异远大于提示词扰动效应。涉及这两行的结论只适用于替代模型本身。
2. **样本量**：替代模型变体 n=3，基线 n=5。winner 层面的 modal 估计在 n=3–5
   下较粗（grok-4-5 基线 3/5 vs 2/5 的弱多数即为体现）；ρ 与位移基于均值表，
   相对可靠。
3. **温度 0.0 ≠ 确定性**：跨次变异来自提供方侧非确定性，已由折半参照量化，
   未与零比较。
4. 两个替代模型的基线自身不稳定（grok-4-5 与 claude-opus-4-6 的折半 winner
   均翻转），其"winner 保持"结论应理解为"在噪声范围内一致"；两者的变体翻转
   /保持同样只能在噪声语境下解读。

## 5. 总结论

**头条结论的稳健性分层明确：基线稳定的模型（Gemini、GPT-5）在全部扰动下
winner 与排序均稳健；基线不稳定的模型（Grok-4.5、Claude）其 winner 本身由
噪声主导，扰动效应无法与固有噪声区分。维度级分数不稳健，不应单独引用。**

- Winner：10/12 条件不变；唯一变体翻转发生在基线弱多数且折半自翻转的模型上，
  且该模型在无扰动时同样翻转。
- 排序：ρ ≥ 0.64；GPT-5 完全在噪声内；Gemini 受良性扰动影响略超噪声；
  Grok-4.5 的变体效应与自身噪声不可区分；Claude 的一切变体效应小于其自身噪声。
- V3 范式消融未改变任何基线稳定模型的 winner——对可信基线而言，项目结论
  不依赖于"约束优化"框架。
