## After running the Agent, a main menu will appear:

### 1.Run Unsupervised Learning (Opens Sub-menu) — run only the unsupervised training module
### Please choose an action:

(1). Only run unsupervised learning
(2). Candidate molecule distribution map (UMAP)
(3). Run script 1 and then script 2 (Suggested)
(4). Run nothing
(5). Exit

###  2.Run Supervised Learning (Regression & Classification) — run only the supervised learning module
###  Please select a task:

(1). Run Regression
(2). Run Classification
(3). Run Both
(4). Exit

### 3.Run Agent Selection (Final Decision) — select the best formulation ratio and generate the Agent response

### 4.Run ALL (Sequence: 1 → 2 → 3) — automatically run everything in order (1 → 2 → 3)

### 5.Exit — quit the program

### How to run:
```bash
python Agent_workflow.py
```
